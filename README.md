# Car Price Prediction Using Machine Learning

## Project Overview

This project predicts the selling price of a used car using Machine Learning algorithms.

## Algorithms Used

* Linear Regression
* Multiple Linear Regression
* Ridge Regression
* Lasso Regression
* Decision Tree Regressor
* KNN Regressor
* Random Forest Regressor
* Gradient Boosting Regressor
* SVR
* Naive Bayes
* Logistic Regression

## Features

* Data Preprocessing
* Feature Scaling
* Model Comparison
* Graphical Analysis
* Flask API
* Model Saving using PKL files

* app.py
